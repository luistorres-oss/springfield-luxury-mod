# Springfield Luxury Mod

Projeto de modificação para The Simpsons: Hit & Run.

## Ideias do projeto

- Adicionar carros de luxo.
- Criar uma versão do Homer com armadura inspirada no Homem de Ferro.
- Manter as características e animações originais sempre que possível.

## Estrutura

- `assets/cars`: modelos dos carros.
- `assets/characters`: modelos dos personagens.
- `src`: arquivos do mod.
- `docs`: documentação e planejamento.

## Status

Planejamento inicial.
